# Together

Together — веб-комната для совместного просмотра видео и звонков. Ведущий открывает файл из локальной библиотеки или загружает его на сервер. До восьми участников заходят по ссылке, смотрят с общей позиции и могут пользоваться чатом, микрофоном, камерой и демонстрацией экрана.

## Быстрый запуск

Установи Node.js 20+. Для HLS также нужны FFmpeg 6+ и FFprobe. Приложение запускается из каталога `together` внутри клона.

```bash
cd together
HOST=127.0.0.1 npm start
```

Открой `http://localhost:3000`. Для второго участника используй другой профиль браузера. На домашнем компьютере можно запустить `npm run share` и скопировать публичное приглашение из комнаты. Для постоянного размещения есть Docker Compose с Caddy.
